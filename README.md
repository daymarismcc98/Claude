# Skafos Artesanal – Reel de Instagram (Remotion)

Edita el video original del taller de velas como Reel vertical para Instagram.

- Formato: 1080×1920, 30 fps, H.264 + AAC, 12.5 s
- Gancho inicial: “¿Quieres crear tus propias velas?”
- Subtítulos animados por escena (Paso 1–3, Resultado, Clases, Al final)
- Zoom suave en cada corte
- Cierre con botón “Reserva tu lugar · Cupos limitados · Link en la bio”
- Textos dentro de la zona segura de Instagram (lejos de la interfaz superior e inferior)

## Uso

```bash
npm install
npm run studio   # vista previa y edición
npm run render   # genera out/skafos-reel.mp4
```

Los textos y tiempos de cada escena están en `SCENES` dentro de `src/InstagramReel.tsx`.
